# Harshit Tiwari | Data Analyst Portfolio

Live site: **https://harshit-insights.github.io**

A single-page portfolio for a Data Analyst, built with plain HTML, CSS and a little JavaScript. No build step and no frameworks. It has a light theme with an optional dark mode and works on phones.

## What is on the site

- **About and skills**: Python, SQL, Excel, Power BI, Tableau, Streamlit, Plotly
- **Three end-to-end projects**, each written as Situation, Task, Action, Result, with a chart and a GitHub link:
  - [Customer Segmentation and Retention Campaign ROI](https://github.com/harshit-insights/Customer_Segmentation_RFM_Analysis)
  - [Product Line Profitability and Margin Performance](https://github.com/harshit-insights/Nassau_candy_data_science_Project)
  - [System Capacity and Care Load Analytics](https://github.com/harshit-insights/uac-care-load-analytics)
- **Experience, education and certifications**
- **Contact details**

## Run it locally

Open `index.html` in any browser. There is nothing to install.

## Hosting

The site is served by GitHub Pages from the `main` branch (root folder). To update it, edit `index.html` and commit. The live site refreshes in a minute or two.
